# NEFT Banking Transaction Analysis

An end-to-end data analytics project on India's **NEFT (National Electronic Funds Transfer)** banking data — 267 banks, ~21,000 bank-month records, June 2008 to June 2020. The project covers the full pipeline: raw data → SQL database → Python cleaning & feature engineering → EDA → interactive Power BI dashboard.

## How to Run

### 1. Python pipeline

```bash
# clone the repo
git clone https://github.com/<your-username>/NEFT-Banking-Transaction-Analysis.git
cd NEFT-Banking-Transaction-Analysis

# install dependencies
pip install pandas numpy matplotlib reportlab

# run the pipeline in order
python python/data_cleaning.py          # -> data/processed/Cleaned_NEFT.csv
python python/feature_engineering.py     # -> data/processed/Featured_NEFT.csv
python python/eda.py                     # -> images/eda_*.png + printed summary
```

### 2. MySQL database

```bash
mysql -u root -p < sql/database_schema.sql

# load data/raw/NEFT.csv into stg_neft_raw (via LOAD DATA INFILE or
# MySQL Workbench's Table Data Import Wizard), then:
mysql -u root -p < sql/data_cleaning.sql
mysql -u root -p < sql/analysis_queries.sql
```

### 3. Power BI

Open `powerbi/NEFT_Analysis.pbix` in Power BI Desktop. The report is pre-built against `data/raw/NEFT.csv` — repoint the data source under **Transform Data → Data Source Settings** if your local path differs.

## Key Findings

- **Market concentration:** the top 5 banks (SBI, HDFC, ICICI, Axis, Citi) account for ~49% of total NEFT value; the top 10 banks account for ~64%.
- **Growth:** total NEFT amount grew from ~2.1M Cr (2008) to ~465M Cr (2019) — a CAGR of roughly 59.5% over 2009–2019 — before a partial 2020 dip (data available only through June, coinciding with COVID-19).
- **Seasonality:** transaction volume is higher around March, consistent with the Indian financial year-end.

Full write-up with charts: [`docs/Project_Report.pdf`](docs/Project_Report.pdf).
